Install over v4.7. Close app, replace files, pip install -r requirements.txt.
Default workspace: %USERPROFILE%\DesktopAIWorkspace. To choose another, set DESKTOPAI_WORKSPACE in CMD before launching main.py. Use a dedicated folder without secrets. New tools always require approval, including reads. Browser navigation uses default browser and existing UI Automation, not Playwright. Word supports plain paragraphs only. Excel copy requires active XLSX format. No shell or deletion tools. Workspace restriction applies to new file tools, not existing desktop mouse/keyboard tools. Local data may be sent to AI provider and saved in task history. Windows/Office live tests not performed.
