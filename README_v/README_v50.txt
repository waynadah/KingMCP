Desktop AI v5.0 — Chat Edition
Requires v4.9 and earlier v4.8/v4.7 modules already installed.
Replace main.py and requirements.txt. Install requirements and run python main.py.
Chat displays saved user prompts, assistant updates and task outcomes. Ctrl+Enter sends.

Use F9 to pause/resume, F10 to stop. Existing approval and screen-sharing dialogs remain.
Memory and workflows are retained; Reset All Tasks clears both. Action log is collapsible.
No changes to the API engine. Windows execution not tested.
